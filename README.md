# re:desktop

A shared desktop availability light for people and cooperating agents, built with Bend.

The native tray menu will show who has access, let the human pause agent access, and display waiting sessions. An MCP bridge will connect independent agent sessions to the same local coordinator. Access is voluntary; people retain ordinary desktop control.

This repository is being developed toward a locally verified MVP. The saved investigation and implementation intent lives in Moment at `~/.moment/intents/re-desktop.md`. Product decisions, protocols and verification evidence belong in `docs/` as they are established.
